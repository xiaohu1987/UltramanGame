# 奥特曼打怪兽 · 回合制小游戏

纯前端（HTML / CSS / JavaScript）回合制对战小游戏：  
玩家选择 **3 名奥特曼**，系统随机派出 **3 只 AI 怪兽**，双方轮流行动并释放技能，直到一方全灭。

## 如何游玩

### 方式一：本地静态服务器（推荐）

在项目根目录执行：

```bash
# Python 3
python -m http.server 8080
```

浏览器打开：`http://127.0.0.1:8080`

### 方式二：直接打开

双击 `index.html` 也可游玩；若图片路径含空格，建议使用本地静态服务器。

## 操作说明

1. **选角阶段**：从候选奥特曼中点选恰好 3 名，点击「开始对战」。
2. **战斗阶段**：
   - 按速度决定行动顺序
   - 玩家回合：点击技能；若技能需要目标，再点击高亮角色
   - AI 回合：自动选择技能与目标
3. **技能类型**：
   - 伤害：攻击敌方
   - 治疗：恢复生命
   - 增益：提升攻击
   - 减益：降低防御
4. **结算**：一方全灭后弹出胜负结果，可「再来一局」。

## 核心模块说明

### data.js - 角色数据定义
- 定义奥特曼和怪兽的属性（生命、攻击、防御、速度）
- 定义技能系统（伤害、治疗、增益、减益）
- 提供角色创建函数

### battle.js - 战斗引擎
- `BattleEngine` 类：核心战斗逻辑（866 行）
- 回合制状态机：管理行动顺序、技能冷却、状态效果
- AI 系统：自动选择技能和目标
- 支持难度调节和自动战斗模式

### ui.js - UI 渲染
- 选角界面：展示候选奥特曼，支持点选
- 战斗界面：渲染角色卡片、技能列表、战斗日志
- 实时更新：HP 条、状态效果、行动顺序

### fx.js - 街机特效系统
- `ArcadeFX` 类：Canvas 粒子系统（2113 行）
- 视觉效果：伤害飘字、连击提示、屏幕震动、闪光
- 音效系统：Web Audio API 生成程序化音效
- 技能特效：光束、迷雾、光环轨迹等

### main.js - 流程控制
- 游戏状态管理：选角 → 战斗 → 结算
- 事件绑定：按钮点击、技能选择
- 难度设置和自动战斗开关

## 游戏特性

- **回合制 3v3 对战**：双方均可释放技能
- **丰富的技能系统**：冷却、治疗、增益、减益
- **智能 AI**：自动选择最优技能和目标
- **街机风格特效**：粒子、震屏、连击、程序化音效
- **难度调节**：可调整游戏难度
- **自动战斗**：可开启 AI 自动操作
- **桌面端布局优先**：响应式设计
